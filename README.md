# תרבות וגילוי

**[לאפליקציה החיה: tarbutgilui-gh.vercel.app](https://tarbutgilui-gh.vercel.app)**

מאיפה בא רעיון, ומי הניע אותו.
שלוש שאלות באפליקציה אחת, על גרף אחד שמצרף שלוש אפליקציות מהתיק:

| מסך | השאלה | מה הוא מפיק |
|---|---|---|
| עץ הרעיונות | ממי ירש ולמי מסר? | אבות וצאצאים של כל רעיון, לפי דורות, עם צבע התרבות |
| תרבות כמנוע | איזו תרבות הובילה כל תקופה, ולמה? | מקל השליחים: המובילה בכל תקופה, הסבר מהנתונים, ארכיטייפ, ומנוע הידע (מי מסרה ומי קיבלה) |
| שרשרת עד הפרס | כמה רחוק הפרס מהשורש? | שרשרת מהעת העתיקה עד זוכה נובל, עם החוליות החסרות |

## מקורות

- [גמד על כתפי ענקים](https://prasnovel-gh.vercel.app/) ([קוד](https://github.com/Anat1969/PrasNovel-GH)): זוכי נובל, נימוקים וקשרי הנחיה.

## הרצה
```
npm install
npm run data      # בונה את src/data/graph.json מהמקורות (או SRC=<תיקייה> לעבודה בלי רשת)
npm run dev
npm run build && npm run preview && npm test
```

## מבנה
- `scripts/build-data.mjs`: מצרף את שלושת המקורות. `scripts/cultures.mjs`: כללי השיוך לתרבות ולתקופה.
- `src/lib/graph.ts`: שושלת, שרשרת, גשרי תחום, הנהגה ומנוע ידע.
- `src/pages/`: Home, Tree, Culture, Prize, Sources.
- `supabase/functions/tarbutgilui-ai`: זיקוק AI (Gemini החינמי, Claude כגיבוי).
- `tests/e2e.cjs`: בדיקות Playwright. `tests/shot.cjs`: צילומי מסך.

## החלטות
- **שושלת רק בקשרים מתועדים.** בעץ אין הסקה. בשרשרת עד הפרס, כשהמתועד נגמר, יש גשר תחום שמסומן כהנחה.
- **שיוך לתרבות הוא פרשנות** לפי מקום ושנה, והכללים גלויים בקוד.
- **מקל השליחים:** בכל מסך סופרים כמה פעמים הרעיון עבר בין תרבויות.
